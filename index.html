📲 Install the app

iPhone / iPad (open this page in Safari):
  1. Tap the Share button (the square with the ⬆ arrow)
  2. Scroll down and choose Add to Home Screen
  3. Tap Add in the top-right corner
Android (Chrome):
  1. Tap the ⋮ menu in the top-right corner
  2. Choose Install app or Add to Home screen
Computer (Chrome / Edge):
  1. Click the install icon (🖥⬇) at the right end of the address bar
  2. Or open the menu ⋮ → Cast, save and share → Install page as app
